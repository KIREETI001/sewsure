# @sewsure/contracts — contract v1 (DRAFT)

The single source of truth for SewSure API routes and record shapes. **Draft, not frozen.** See [CHANGELOG.md](CHANGELOG.md).

```
schemas/*.schema.json         JSON Schema 2020-12, one file per record (source of truth)
openapi/sewsure.v1.yaml       OpenAPI 3.1 routes, $ref-ing the schemas
fixtures/*.json               mock scenarios ("mock": true), generated by scripts/build_fixtures.py
generated/python/             Pydantic v2 models for services/api  (generated, never hand-edit)
generated/ts/sewsure.v1.ts    TypeScript types for apps/mobile     (generated, never hand-edit)
scripts/                      validate.py, build_fixtures.py, codegen.py
tests/                        contract tests (pytest) and a TypeScript type check
```

## Use it

**services/api (Python 3.12):** `pip install -e packages/contracts`, then:

```python
from sewsure_contracts.design_revision_schema import DesignRevision
```

**apps/mobile (TypeScript):**

```ts
import type { components } from "@sewsure/contracts";
type DesignRevision = components["schemas"]["DesignRevision"];
```

Request and response types per route live under `paths` and `operations` (e.g. `operations["listDesigns"]`).

**Fixtures:** load `fixtures/<scenario>.json`. Each one bundles project, garment, measurements, job, design list and revisions (plus a cut plan, DIY steps and tailor records where they apply). Values are synthetic and illustrative, not measured evidence.

| Fixture | Shows |
|---|---|
| `woven_shirt_crop_pass` | Two designs that pass (not three). One edit, so rev 1 is `SUPERSEDED`. Cut plan, DIY steps, progress, a quote. |
| `lengthening_impossible` | `FAILED_CHECKS`, `INSUFFICIENT_LENGTH`, residual −150 mm, a supported crop offered instead. |
| `needs_input` | `NEEDS_INPUT`: `shoulder_to_hem` is only a vision suggestion (`confirmed_at: null`). |
| `idea_only` | `IDEA_ONLY`: knit tee to corset top, no recipe, no cut plan, brief labelled `inspiration_only`. |
| `stale_after_measurements_change` | A passed revision whose measurements were replaced: `stale: true`, state unchanged, cut plan route returns 409 `REVISION_STALE`. |
| `job_failed_no_designs` | Failed job with a recoverable error and an empty design list. |

## Change it

1. Edit `schemas/` or `openapi/`. If a fixture is affected, edit `scripts/build_fixtures.py` too.
2. Run `python scripts/build_fixtures.py` and `python scripts/codegen.py`.
3. Run `python scripts/validate.py`, `pytest`, `pyright` and `npm run check:ts`.
4. Add a CHANGELOG entry that names the consumers affected, and get review from them (A2).

Setup: run `pip install -e ".[dev]"` and `npm install` inside `packages/contracts`.
